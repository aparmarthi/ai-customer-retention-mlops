# ai-customer-retention-mlops
End-to-end AI Customer Retention System that processes 28GB of real-world subscription data to predict churn. Includes scalable ETL, MLflow tracking, FastAPI + Streamlit deployment, and ROI simulation—built locally, architected for cloud.

## Capstone Data Collection

This repository contains datasets explored for my capstone project:
**Early Churn Prediction for Subscription-Based Apps**.

### Datasets
1. KKBox Churn Prediction Dataset (primary, GB-scale, Git LFS)
2. Telco Customer Churn Dataset
3. Online Retail II Dataset

### Data Handling
- Large datasets are tracked using Git LFS
- Sample subsets are included for inspection
- Dataset-specific READMEs document source and relevance
